## 2. 定位澄清：CUF ≠ 「给 AI 一个世界模型」

为避免审稿误读（把本工作归为又一个 world-model / model-based RL 工作），此处明确本框架与「世界模型」的边界。

### 2.1 世界模型是什么

AI 中的「世界模型」（Dreamer、model-based RL 等）是**预测性结构**：给定当前状态 s 与动作 a，预测下一状态 s′（以及奖励）。其核心任务是回答「接下来会发生什么」，通常通过预测误差 / 梯度下降习得。

### 2.2 CUF 与世界模型的本质差异

| 维度 | 世界模型（world model） | CUF（自指认知框架） |
|---|---|---|
| 核心问题 | 接下来会发生什么（预测） | 哪些因果公理还成立、存续代价多大、何时整个崩掉（信念维持） |
| 世界与模型的关系 | 模型是环境的内部近似，二者混在一起 | **明确分离**：W1/D = 世界真规律（只读硬编码真值），W2 = 被测的认知结构——我们测的是后者能否存续 |
| 学习机制 | 预测误差 / 梯度下降（连续） | **反例驱动的公理降级 + 边界细化**（离散、规则式、无梯度，类似信念修订） |
| 成本与崩溃 | 无 | **核心命题**：W₂ 存续须支付稳态成本 C_H（struct/adapt/extend），超预算触发 Γ脆 解体（热力学式代价核算） |
| 结构指向 | 指向外部环境 | **自指**——结构指向自身，意识被定义为自指运行的副产品（无因果力） |

### 2.3 关键：本实现里「有世界模型结构」的根本不是 LLM

按**反套壳四铁则**（真值判定零 LLM）：

- **世界模型式的结构（W2 公理引擎）是硬编码的确定性机制**，不是神经网络、不是 LLM；
- **LLM（7B）仅充当「动作建议器 + 语义转译」**，被刻意排除在裁决之外；
- 因此，本实验**没有**给 LLM 一个世界模型，而是用一个独立、硬编码的自指公理系统充当认知主体，拿 LLM 只提动作建议。

> S29.11 的「知道≠会做」现象（7B 注入受伤信号+记忆+逃跑规则后仍战斗至死）正是该边界的实证：**LLM 没有、也未被给到一个能指导行为的世界模型**。

**一句话**：CUF ≠ 「给 AI 一个世界模型」——CUF 是「一个必须持续付代价才能不崩的自指公理系统」；它内含类世界模型的公理层（W2），但其独创性在**成本（C_H）+ 崩溃（Γ脆）+ 自指**，且本实现中这个「模型」是硬编码引擎，LLM 反被挡在世界模型与裁决之外。

## 8. 结论

1. **降级机制优势成立（P_W2_5）**：机制组对齐分均值普遍高于对照组（离线路 +0.300, p=0.0039；7B 判别分 18/36 种子扩样后 6 组 pooled 全部显著），差异来源 = 机制组反例驱动的规则修正（降级+边界细化）在剧本世界维持更稳定的一致性。
2. **对照组无纠错能力**：无降级/边界细化，纯频率拟合无法应对规则变化（A_M1 剧本对照组均值仅 0.333，机制组恒 1.0）。
3. **规则单调细化（P_M1）**：机制组边界条件净增加且单调（A_M1×2 / A_W1×1 / A_W2_5×3）。
4. **感知边界（P_W1）**：dirty_total=0，无超出白名单能力的观测。
5. **Γ脆 机制（P_C supported / H_L falsified）**：超预算即解体获实证；功能死亡可未经超预算直接触发，渐进式崩溃假设被推翻。
