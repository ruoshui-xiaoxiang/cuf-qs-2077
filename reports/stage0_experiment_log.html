一、项目总目标

在《赛博朋克2077》中构建真实运行的 CUF（自指认知框架）实验系统，完成 「公理注入 → 假设生成 → 动作执行 → 观测采集 → 反例判定 → 公理降级 → QS 收敛监控」完整闭环， 产出 CUF 机制组与纯统计拟合对照组的论文级对比数据（收敛曲线、降级日志、C_H 成本曲线、虚拟寿命、量化指标）。

二、理论基础：CUF v7 对齐

理论四层：D（度规因果结构）、M（规则接口）、W₁（现象场）、W₂（稳态自指体）。核心命题：任何 W₂ 持续存在须支付稳态成本 C_H（struct / adapt / extend 三子维度），C_H ≤ B_entropy，超预算触发 Γ脆 解体；意识是自指运行的副产品，无因果力。

三、反套壳四铁则（不可变量）

  1. 裁决权下沉：真值判定、降级触发、QS 收敛计算、ICC 审计全部由独立 Python 模块硬编码实现；LLM 仅做语义转译与实验假设生成，无任何最终判定权。
  2. 数据流解耦：四层架构走结构化 JSON 数据链路；自然语言仅为人类可读输出，不参与核心决策。
  3. 可单测验证：QS 计算、降级判定、ICC 审计必须能脱离 LLM 独立运行，输入模拟数据即可验证。
  4. 因果链可追溯：每次公理变更、收敛判定必须对应明确的观测数据与阈值触发记录，禁止黑盒决策。

5.1 架构与交付物

Python 侧作为 TCP 服务端监听 127.0.0.1:20770，游戏内 CufBridge 模组（Lua）作为客户端主动连接， 双向通信采用 JSON 行协议（帧终止符 \r\n），含心跳保活、断连检测与 15 秒收包看门狗。

5.2 排查全程：四大根因（均已解决并记录在案）

#故障现象根因修复方案
1模组加载报错，找不到 RedSocketCET 沙箱隔离，require 只能解析本模组目录改用 GetMod('RedSocket') 懒加载
2连接建立但收不到任何回包帧终止符不匹配，RedSocket 按 \r\n 分帧全链路改用 \r\n 帧终止符
3偶发僵死连接，模组误判在线TCP 半开连接无感知增加 15 秒收包看门狗，超时强制重连
4hello/ping 全通，但下发代码执行必然超时CET 沙箱移除 load / loadstring，运行时无法编译任意代码字符串任意 Lua 下发路线废止，改白名单结构化指令协议（见 5.3）
根因 4 的取证方式：在游戏内按 ~ 打开 CET 控制台直接执行 print(type(load), type(loadstring), _VERSION)，返回 nil nil Lua 5.1—— 一次性实锤两件事：① load/loadstring 均被沙箱移除；② CET 运行的是 Lua 5.1（非 5.4），后续所有模组代码按 5.1 语法编写。

5.3 协议变更：proto 2 白名单结构化指令（用户批准，锁定决策 15）

Python ↔ 游戏不再下发任意代码，改为调用模组预注册的白名单处理函数：

方向报文格式
Python → 游戏{"t":"call","id":2,"fn":"add","args":[1,1]}
游戏 → Python{"t":"resp","id":2,"ok":true,"data":2}
  • 首批注册函数：echo / add / lua_version / list_fns。
  • 模组端全链路 pcall 保护，未知函数、执行异常均以结构化错误回传，永不静默超时。
  • S4 数据采集与 S5 动作执行将来一律以「新增注册函数」方式扩展，与 W3 白名单铁则天然对齐。
