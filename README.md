# CUF-QS：复杂交互环境中的具身动作控制与证据闭环系统

面向《赛博朋克 2077》持久世界的具身动作控制系统实验，含完整逐轮原始归档。

本仓是**脱敏公开版**：只收运行核心、实验证据与处置结论，不收平台专用底层接入实现。
纳入与排除范围见 [EXCLUDED_FROM_PUBLIC.md](EXCLUDED_FROM_PUBLIC.md)。

## 这个仓库是什么

- 复杂交互环境中的具身动作控制系统
- 带证据闭环和结果语义分层的实验系统
- 以执行可控、证据可复检、日志可审计为中心的工程系统

## 这个仓库不是什么

它**不是一次高置信度的理论验证**。此前的高层理论叙事保留为历史背景，不再是当前交付中心。
继续扩写高层理论、把收敛语言当作核心产品成果、用局部实验支撑更强的理论结论、
把工程连通性结果混同为最终语义证据——这四项已明确降权。

## 结果语义（对外表述一律遵守）

任何动作结果未经确认语义，不得写成事实成功。四类状态必须区分：

- `accepted` — 请求被接受
- `completed` — 流程跑完
- `confirmed` — 有独立证据回指确认
- `unconfirmed` — 无独立证据，只是没报错

动作控制另有分层：`stable` / `conditional` / `experimental`。实验性动作不得静默进入默认正式路径，
必须显式启用并独立归档。

## 复现边界（重要）

公开版**不包含**游戏侧桥接模组与原生插件实现，因此：

- **可以**在本仓独立复算的：全部离线自测与回归（mock 驱动，不需要游戏、不需要 GPU）
  → `py tests/_run_regression.py`
- **不可以**在本仓独立跑通的：实机闭环。`tests/live_native_evidence.py` 的前置是游戏侧桥接端口
  与原生状态服务就绪，而这两者属于底层接入区，不在公开范围。
- 实机数据口径（作者裁定）：实机数据必须走本地 7B 双路出真实对齐分；
  零模型/确定性嵌入产生的实机数据属无证据低质量数据，不得作为取证依据。

也就是说，本仓公开的是**已归档的实机结果 + 可独立复算的离线系统**，
不是"clone 完就能在我机器上重跑一遍实机"。这一点不在这里含糊。

## 数据可得性

- `logs/` 下 41 个批次目录共 2615 个文件，逐轮 `rounds.jsonl`、`report.json` 与统计产物全部随仓公开，
  含此前被体积理由挡在库外的 `logs/formal_batch_7b_v3/`（1992 个文件，最大单文件 0.9 MB）。
  判据改为**证据完整性优先**：凡结论引用的原始归档，就必须在仓内可查。
- 实机截图（`*.png`）不入本仓，仓库内只有结构化数据与文本。
- `provenance/version_lock_evidence.json` 是实验环境的证据锚点：游戏版本、模组栈版本、
  硬件与 12 条 SHA256 指纹。它从私有仓的 `s1_backup/version_lock.json` 原样抽取，
  只剥掉 `ops_notes`（逐版模组实现与底层接入操作笔记，§D 保留私有）与 `overlay_binding`，
  并在件内登记了原件 SHA256，持有原件者可自验抽取未改动作证字段。
