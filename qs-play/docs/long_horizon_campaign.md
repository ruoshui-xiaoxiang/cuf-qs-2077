# 剑星 AI 长程交互测试战役（Campaign）

> 目标：用多会话、可恢复、可审计的方式，把伊芙在游戏里的**操作面、交互面、UI 面、直播面**逐项测通，形成一张可信的交互矩阵。
> 不是“跑一遍流程”，而是“每个动作都有键位、前置、预期、实测、证据、失败原因”。

## 0. 完成定义（Definition of Done）

1. **覆盖**：80 个可绑定动作覆盖 ≥80%，27 种世界交互提示覆盖 ≥80%；关键项 100%（存读档、移动、格挡/闪避、菜单、直播音频）。
2. **关键闭环**：存读档脱困、死亡复活、卡地形恢复各至少 1 次实测。
3. **战斗**：连续 3 场遭遇中，反射层能触发、能一套打死或连续撤退脱战；玩家非测试性死亡 ≤1 次。
4. **直播**：直播伴侣 1080p60 硬件编码连续 30 分钟；RAM 空闲 ≥3GB、GPU ≤97%、无持续掉帧；解说音频被系统声捕获。
5. **证据**：每个用例都有 before/after 截图或 state 快照、原始读数、结论；失败项写明失败点和下一步。
6. **文档**：交互矩阵、键位表、菜单路径图、直播检查单全部更新。

## 1. 当前基线（开工前已确认）

- 桥：v3.2 只读，state 87~106ms；HUD 5Hz（HP/盾/敌 HP/盾）。
- 战斗：reflex v2（固定连招 + 撤退）；Q 语义未知，E=格挡，F=交互。
- 解说：伊芙人设 + MiMo 克隆声线；固定战斗句已预合成，idle/travel 动态生成。
- 资源：31.8GB RAM / 空闲约 5.9GB；5060 Ti 16GB / 已用 11.17GB / 94%；游戏 1440p 未锁帧。
- 直播：直播伴侣；建议 1080p60 + 硬件编码 + 系统声音捕获。
- 未知：存读档入口、闪避键、菜单键、技能槽 1~5、锁定键、目标身份绑定、CNS 菜单路径。

## 2. 原则与恢复

- **先存档再冒险**：每个高风险用例前复制存档到 `runs/campaign/saves/`；不用游戏内覆盖式存档做唯一备份。
- **一个变量**：一次只改一个键/一个动作；不同时测“闪避+技能”。
- **双通道判据**：引擎坐标/速度 + 截图目视；HUD 数字只做血量/盾，不做位置。
- **寻路**：走开阔地，不直线贴扫描敌人；小步走 + 截图复核；Tab 扫描辅助。
- **战斗**：HP<50% 或 3 个以上敌人 → 撤退/读档，不在测试里硬拼。
- **只读边界**：不改内存/血量/坐标；CNS 外观 mod 只做展示测试。
- **直播资源**：云端 TTS；不在游戏+直播时跑本地大模型/神经 TTS。

## 4. 每个会话的执行循环（45~60 分钟）

1. **Preflight**：桥 state 新鲜；复制存档；资源采样；选 3~6 个用例。
2. **Baseline**：截图 + state + HUD。
3. **执行**：只改一个变量；失败立即停，记录。
4. **恢复**：读档/撤退/回营地；保存；更新矩阵。
5. **收尾**：证据归档；写一句结论；下一会话的 Gate 检查。

## 5. 证据格式

```
runs/campaign/<phase>/<case_id>/
  before.png / after.png
  state_before.json / state_after.json
  metrics.json        # 位移、时间、HP/盾、资源、延迟
  notes.md            # 动作、键、预期、实测、结论、失败原因
```

矩阵：`data/interaction_matrix.csv`，字段：case_id, phase, surface, action, key, precondition, expected, observed, status, evidence, notes。

## 7. 停止/回滚条件

- 存档损坏、桥连续崩溃、菜单无法退出、角色反复软锁。
- 直播时 RAM 空闲 <2GB 或 GPU 持续 >99%、明显掉帧。
- TTS/chat 费用异常或 key 失效。
- 任一关键键位（E/F/闪避/菜单）与预期冲突且无法校准。

出现以上情况：停止测试 → 读档/重启 → 记录 → 调整计划，不硬推。

## 8. 立刻可执行的第一步

1. 复制存档；打开菜单，确认存/读档路径（P0-1~3）。
2. 校准 E/F/Q/Alt/Tab/R/中键/M（P0-6）。
3. 游戏锁 60 帧；关掉多余直播进程；RAM 空闲到 8GB 再开播（P0-8）。
4. 跑 M1 走/跑/冲刺与 C2/C4 格挡/闪避对照，拿到第一批键位与数值。
